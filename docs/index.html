Wheelhouse

Kubernetes clusters, in your pocket.

Wheelhouse is a native iPhone and iPad app for watching and managing several Kubernetes clusters at once. It talks directly to your clusters’ API servers: no backend, no account, no analytics.

  • Fleet dashboard with health, capacity and the problems that need attention across every cluster.
  • Cluster dashboards with nodes, workloads, events and CPU/memory from metrics-server or Prometheus.
  • Resource browser with search, namespaces, YAML view, edit and apply.
  • Actions such as scale, restart, delete and cordon, each previewed with a server-side dry run.
  • Live logs, a terminal into containers, and port forwarding.
  • Safety: mark clusters as production (typed confirmation for every change) or read-only.
  • Face ID lock, optional iCloud Keychain sync, widgets and background alerts.

Wheelhouse is free and open source under the MIT license.
