Support

Found a bug, have a question or want a feature? Open an issue on GitHub. Please include your iOS version, the app version (Settings → About → Version) and what you expected to happen.

Open an issue on GitHub →

Never paste a kubeconfig, token, certificate or private key into an issue. If a connection fails, use Copy diagnostics in the app: the report it copies has credentials removed.

Common questions

How do I add a cluster?
Tap Add Cluster and either import a kubeconfig file or enter the API server URL with a service-account token. You can also share a kubeconfig file to Wheelhouse from Files, Mail, WhatsApp or Telegram.

Can I try it without a cluster?
Yes. Tap Explore Demo on the welcome screen (or in Settings) to explore a simulated fleet.

The connection fails with a TLS error.
Make sure the kubeconfig includes the cluster’s CA certificate (certificate-authority-data) and that the server address matches a name or IP in the API server certificate. The connection test shows the exact reason.

Logs say “too many open files”.
That message comes from the node, not the app: the kubelet has run out of inotify instances. Raise fs.inotify.max_user_instances and fs.inotify.max_user_watches on the node. Wheelhouse falls back to polling for new lines meanwhile.

Metrics are missing.
Install metrics-server in the cluster, or add a Prometheus URL in the cluster’s settings.
