Support

Found a bug, have a question or want a feature? Open an issue on GitHub. Please include your macOS version, the app version (Wheelhouse, About Wheelhouse) and what you expected to happen.

Open an issue on GitHub

Never paste a kubeconfig, token, certificate or private key into an issue. If a connection fails, use Copy diagnostics in the app: the report it copies has credentials removed.

Reporting a security problem

If you find a way around a guard described on the security model page, or any way to make Wheelhouse change a cluster without your confirmation, please do not post it publicly. Use GitHub’s private vulnerability reporting on the repository (Security tab, Report a vulnerability).

Common questions

My cluster is read-only and I cannot change anything.
Clusters found in your kubeconfig files or by Landfall start read-only on purpose. Open the cluster’s settings and allow changes. For a Production cluster this asks for Touch ID or your password.

A command in the terminal says “Wheelhouse: change not confirmed”.
The confirmation sheet was declined or timed out after 120 seconds. Run the command again and confirm it in the sheet.

The terminal says Unguarded.
The shell is no longer using Wheelhouse’s kubeconfig, usually because KUBECONFIG was changed or a command used --kubeconfig. Press Restore to go back.

Wheelhouse inserted a command but did not run it.
That is intended. Commands from First Mate and Rigging are only placed at the prompt. Press Return to run it.

The connection fails with a TLS error.
Make sure the kubeconfig includes the cluster’s CA certificate and that the server address matches a name or IP in the API server certificate. The connection test shows the exact reason.

Metrics are missing.
Install metrics-server in the cluster, or add a Prometheus URL in the cluster’s settings.

A widget shows old data or “No data”.
Widgets show what the app last wrote while it was running, at most every five minutes and only when something changed. Open Wheelhouse and let it check your clusters, or add the widget again.

The menu bar item is gone.
Turn it on in Settings, Crow’s Nest. If you want checks to continue with no window open, also turn on Keep running in the menu bar.

Does Wheelhouse work offline or with a VPN?
It connects to the same addresses your kubeconfig does, so it works wherever kubectl does. Unreachable clusters are shown as unreachable and are checked again at the next health check.
