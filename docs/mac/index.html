Wheelhouse for Mac

Kubernetes clusters, native on your Mac.

Wheelhouse for Mac is a native app for watching and managing several Kubernetes clusters at once. Like the iPhone and iPad app, it talks directly to your clusters’ API servers: no backend, no account, no analytics.

Not released yet; the first release will appear here.

  • Wheelhouse for Mac will require macOS 27 on an Apple silicon Mac.
  • It will be a signed, notarized disk image with in-app updates.
