Wheelhouse for Mac

Kubernetes clusters, native on your Mac.

Wheelhouse for Mac is a native app for watching and managing several Kubernetes clusters at once. Like the iPhone and iPad app, it talks directly to your clusters’ API servers: no backend, no account, no analytics.

Download the latest release (a notarized disk image)

  • Requires macOS 27 on an Apple silicon Mac.
  • Open the disk image and drag Wheelhouse to Applications. The app is signed with a Developer ID certificate and notarized by Apple.
  • Updates arrive in the app (Wheelhouse, Check for Updates…) and are verified with an EdDSA signature before they are installed.
