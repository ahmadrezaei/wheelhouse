Wheelhouse for Mac

Kubernetes clusters, native on your Mac.

Wheelhouse for Mac is a native app for watching and managing several Kubernetes clusters at once. Like the iPhone and iPad app, it talks directly to your clusters’ API servers: no backend, no account, no analytics.

A free, open-source, native Mac alternative to Lens.

Download Wheelhouse for Mac

  • Requires macOS 27 on an Apple silicon Mac. English only for now.
  • A signed, notarized disk image. Updates arrive inside the app.
  • Also coming to the Mac App Store as a sandboxed edition with a few features left out: see the two editions.
