Wheelhouse for Mac

Privacy

Applies to Wheelhouse for Mac. The same principles apply to the iPhone and iPad app; see the full privacy policy.

In short: no accounts, no analytics, no advertising, no tracking, and no server run by the developer. Your data stays on your Mac, and the app talks only to the clusters and services you point it at.

What stays on your Mac

  • Cluster settings (names, addresses, colours, safety options), window layout, saved layouts and the Rail are stored in the app’s folders.
  • Credentials (tokens, client certificates and keys, API keys) are in the Mac’s keychain. Clusters you choose to sync appear through your iCloud Keychain, which Apple encrypts end to end. Sync is off by default.
  • Activity history and command output are stored locally. Activity never contains Secret values or request bodies.
  • The kubeconfig scan (Moorings) looks for kubeconfig files only where you allow, shows the result and imports only what you choose.
  • Terminals use a temporary kubeconfig that is deleted when the session ends. Wheelhouse does not read what you type in a terminal except to recognise the command line for confirmations, and that stays on your Mac.

Widgets

The desktop widgets read a small summary file the app writes into its shared app group folder: cluster names, environments, health, node and pod counts, and, for failing pods, their names, namespaces and reasons, plus the top issue text for each cluster. It holds no credentials and no Secret data. The widgets make no network connection.

What the app connects to

  • Your Kubernetes API servers and Prometheus addresses, the ones you add.
  • The tools you have installed and ask it to use: kubectl, helm, flux, git, trivy, and your cloud command-line tools. Those tools make their own connections under their own configuration.
  • Updates. About once a day (you can turn it off in Settings) the app requests a small update feed from GitHub Pages, and downloads an update from GitHub Releases. GitHub sees your IP address and the app version, as with any web request. No cluster information is included.
  • First Mate contacts the Anthropic API only when you use it, with your own API key and under your own agreement with Anthropic. See below.
  • Survey scans (optional, started by you) let Trivy download its vulnerability database from its public registry and contact the image registries you already use.
  • Artifact Hub (opt-in) is asked for chart names and details only if you turn on its chart search in Chart Room.
  • A Trivy download happens only after you approve the exact file, address, size and SHA-256 shown in the approval sheet, and only when a pinned release is configured in your build. Otherwise Wheelhouse uses the trivy you installed.
  • Image pull secrets. If you turn on “Use the cluster’s imagePullSecrets” for a cluster before a scan, the app reads that cluster’s pull secrets and gives Trivy only the matching registry’s credentials, in a temporary private folder deleted when the scan ends.

First Mate

  • Off until you add your own Anthropic API key. The key is stored in the Mac’s keychain on this device only and is never synced.
  • Your question and the cluster information First Mate reads with your permission go directly from your Mac to Anthropic. Nothing passes through a server of ours.
  • Before anything leaves your Mac it is redacted: Secret values are never read or sent, and tokens, keys, certificates and passwords are replaced with a marker. You can add your own patterns.
  • You can see exactly what was sent for every message.
  • First Mate may read a cluster by default, except Production clusters, where it asks your permission first, per conversation. You can set any cluster to Never.
  • Conversations are stored on this Mac only, encrypted with a key in the keychain, and deleted after 30 days by default (7, 30 or 90 days, or keep). Delete All removes them and the key.

Beacon

Beacon is off by default. When you turn it on, the AI agents you approve can read cluster information through Wheelhouse over a local connection on your Mac, with the same redaction rules. Wheelhouse does not send anything to those agents’ makers; what an agent does with the information is governed by that agent and your agreement with its provider.

Not collected

Wheelhouse has no analytics, advertising or crash-reporting SDKs, and does not collect your name, email, location or usage statistics.
