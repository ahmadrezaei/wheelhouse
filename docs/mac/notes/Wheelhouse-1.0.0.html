Wheelhouse for Mac 1.0.0

The first release of Wheelhouse for Mac: a native Kubernetes manager for your whole fleet, with the same safety model as Wheelhouse for iPhone and iPad.

What’s in it

  • Workspace. Windows, tabs and split panes for any mix of clusters, with layouts you can save as Stations. Each pane shows which cluster it is on, and Production is always marked.
  • Deck Terminal and Gangway. A real shell where kubectl, helm and your other tools work against the pane’s cluster through a guard that applies the app’s rules: read-only clusters refuse changes, and Production changes need your confirmation.
  • Chart Room. Helm releases, charts and repositories: install, upgrade, roll back and uninstall after a review of exactly what will change.
  • Survey. Vulnerabilities, configuration problems and access risks across the fleet, from Trivy Operator reports or a scan you start.
  • Tides. Flux and Argo CD at a glance: what is out of sync or failing, with sync, reconcile, suspend and a dry-run Flux diff against a local folder.
  • Landfall. Find and add your EKS, GKE and AKS clusters using the cloud sign-in you already have.
  • First Mate. An assistant that explains failures and drafts YAML and commands, using your own Anthropic API key. It never changes anything itself, and Secret values are never sent.
  • Beacon. A local MCP server so the AI agents you already use can read cluster state through Wheelhouse’s redaction and safety rules. Off by default.
  • Compass and the Rail. Command-K to find any action, resource, cluster or layout, and a strip of pinned items with Command-1 to 9.
  • Crow’s Nest. A menu bar item that keeps watching cluster health after you close the last window, and notifies you about crash loops, failed jobs, unready nodes and unreachable clusters.
  • Widgets. Fleet Health and Cluster widgets for the desktop and Notification Center.

Good to know

  • Every change, from any part of the app, goes through the same confirmation and is recorded in the Activity window.
  • Wheelhouse has no account and no server. Your clusters, credentials and settings stay on your Mac.
  • Rigging, declarative extension packs for custom resources, comes in a later update.
