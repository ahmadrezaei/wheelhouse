Wheelhouse for Mac

Every cluster, at the helm. Now with the whole deck.

The native macOS 27 companion to the Wheelhouse iPhone and iPad app. Same product, same palette, same safety model, done the Mac way: a multi-pane workspace, local kubeconfig and cloud discovery, a guarded local terminal, Helm, GitOps, security scanning, an AI first mate on your own Claude API key, and a local MCP server. Distributed as a notarized Developer ID download.

SwiftUI + AppKit, not CatalystDeveloper ID, notarizedLiquid Glass sidebar & toolbarOne gate for every changeDiscovered contexts start read-onlyNo Wheelhouse backend

00Feature names

Original names, nautical like the product. Spec: design/mac/DESIGN-MAC.md. Cost monitoring is intentionally not included (owner decision).

MooringsLocal kubeconfig discovery: KUBECONFIG, ~/.kube, extra folders, live watching, exec plugins
GangwayThe guarded local API gate that lets kubectl and helm work while every change still passes the safety model
Deck TerminalA real local shell per context with KUBECONFIG preset and a persistent Production banner
Chart RoomHelm: repositories, chart search, install with schema hints, dry-run diff, releases, history, rollback
StationsSaved workspace layouts (tabs, split panes, linked panes), bound to clusters or used as templates
RailPinned clusters, resources, Stations and commands under the toolbar; ⌘1–⌘9
Compass⌘K command palette and search over every action and every indexed object
Manifest EditorYAML/JSON with cluster OpenAPI validation, autocomplete, folding, multi-document, diff vs live
SurveySecurity center: CVE rollups (Trivy), access and workload risk findings, fix guidance, export
TidesGitOps for Flux and Argo CD: status, diffs, sync, refresh, reconcile, suspend, resume
LandfallCloud cluster discovery for EKS, AKS and GKE with your local CLI credentials
First MateAsk AI with Claude on your own API key: reads through tools, proposes, never mutates
BeaconBuilt-in local MCP server, off by default, read-only by default, never writes to Production
RiggingDeclarative extension packs: CRD views, commands, health rules. No third-party code in v1
Crow's NestMenu bar extra with fleet health, sessions, Beacon state and notifications
